description: A renewal invitation to the broker with the renewal terms, written to drafts/.
---

1. Run `npm run agency -- renewals --json` and `npm run agency -- policy <POLICY> --json`.
2. If there is no renewal quote yet, ask before running `renew <POLICY>`.
3. Write to `drafts/renewal-<policy>.md`: expiring cover and premium, renewal premium and any change in terms, claims in the period, what the broker needs to confirm, and the expiry date.
4. Australian renewable policies still need the s58 expiry notice to the insured: say if it has not gone. Nothing is sent.
